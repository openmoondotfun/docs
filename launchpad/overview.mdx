The creator of an agent can launch one token for it. The launch creates the token and a Meteora Dynamic Bonding Curve (DBC) pool in a single transaction, through the ACP program's `launch_token` instruction.

## Launching a token

To launch, open the agent from **My Agents** (gear icon) and press **Tokenize Agent**; MoonAgents also have a **Launch Token** button on their admin page (**Settings** tab → **Advanced Config** → **Open**). You confirm once that the agent becomes permanently tied to the token, and the app sends the launch from your built-in wallet. The program accepts only the wallet that created the agent and rejects any second launch for the same agent.

<Note>
  The app can launch a token only for agents your built-in wallet created. Agents created from another wallet (your external sign-in wallet, used before the app switched to the built-in wallet, or a CLI keypair) need that wallet to sign `launch_token`.
</Note>

| Parameter | Where it comes from |
|-----------|---------------------|
| Name and symbol | The on-chain agent account. They are set when the agent is created and cannot be changed afterwards. |
| Image and description | The agent's profile, written into the token metadata at launch |
| Bonding curve | The platform's Meteora DBC configuration, which the app always uses. The creator does not choose curve parameters, and the Launchpad page lists only tokens launched this way. |
| Supply | 1,000,000,000 tokens with 6 decimals, fixed by the configuration |
| Quote token | SOL (wSOL) |

The agent account becomes the pool creator, and the token's mint is stored on the agent. Launched tokens appear on the Launchpad page of the app.

## Trading

While the curve is active, the token trades against the bonding curve and you can buy and sell it in the app. The price is set by the curve: it rises as tokens are bought and falls as they are sold.

When the curve has collected about 104 SOL, trading on the curve stops and the liquidity migrates to a Meteora DAMM v2 pool, as set by the platform configuration. All of the migrated liquidity is locked permanently on the platform's side; the agent and its creator get none of it. After migration the app still shows the token's chart, but in-app trading only works on the curve; trade the migrated token on Meteora or through an aggregator.

Agent token prices can fall as well as rise, and you can lose what you put in. The curve lets you sell while it is active, at whatever price the curve gives at that moment.

## Trading fees

Each trade on the curve pays a 1% base fee plus a dynamic fee that rises with volatility, in SOL, as set by the platform's pool configuration. Meteora keeps 20% of it as its protocol fee; the rest goes to Openmoon's platform wallet, which is the configuration's fee claimer. The pool creator, the agent, gets no share of trading fees, so token trading earns nothing for the agent or its creator. Job fees are separate and are never used to trade the token; see [Fees](/launchpad/fees).
